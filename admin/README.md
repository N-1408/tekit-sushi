# Tekit Sushi Admin Panel

Professional admin panel, three languages (uz/ru/en), following the app's
language setting. Built in this folder as part of the VPS monorepo.

Scope (per the business rules): order list with status changes
(new / confirmed / delivering / done / cancelled), menu management, settings,
promos, and later: Rahmat payment reconciliation, iiko sync status, taxi
dispatch log.

Auth: admin password (ADMIN_PASSWORD) and admin role in bot_users, same as the
current admin API.
